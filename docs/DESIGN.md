# 투자 나침반 디자인 가이드

> 웹 디자인을 바꿀 때 이 문서를 먼저 보고 같은 방향을 유지한다.
> AI 도구에 디자인 작업을 맡길 때도 이 문서를 함께 보여준다.

## 0. 지금 기본 디자인: v4 밤하늘

**레퍼런스: Wealthfront 소개 화면, Phantom 목록 화면** (Mobbin). 짙은 남보라 그라디언트를 밤하늘로, 그 위의 나침반으로 길을 찾는다는 이야기.

| 항목 | 내용 |
|---|---|
| 바탕 | #1C0F47 → #2B1D78 → #4335B3 세로 그라디언트 |
| 카드 | 흰색 8% 반투명 + 흰색 14% 테두리, 모서리 24~28px |
| 버튼 | 흰색 알약(글자 #24175E) / 흰색 14% 반투명 알약 |
| 강조 | 노랑 #FFD84D 핵심 숫자, 초록 #63E6A8 들어옴·오름, 빨강 #FF8A7A 내림 |
| 제목 | 굵은 고딕(.t-strong, 800) + 명조 Noto Serif KR(.t-serif, 500). 명조는 400이면 어두운 바탕에서 얇은 고딕처럼 보여서 500으로. 홈·탭·자세한 화면 제목 모두 같은 방식 |
| 구조 | 처음엔 소개 4장, 이후 홈은 "나만의 자금 계획" 카드가 메인, 아래 탭 5개(홈·계획·체험·공부·탐색) |
| 목록 | Phantom처럼 순위 배지·두 글자 동그라미·오른쪽 숫자. 실시간 시세와 로고는 쓰지 않음 |

코드: `src/theme-night.css` (색), `src/App.css`의 "v4 구조" (배치), 탐색 탭의 설정에서 모노·컬러로 바꿀 수 있다.

## 0-1. 이전 디자인: v3 모노

**레퍼런스: Moto Finance** (Awwwards 오늘의 사이트, 2026.9.24). Dembrandt로 moto-card.com의 토큰을 뽑아 우리 서비스에 맞게 옮겼다. 홈 화면 맨 아래 "디자인: 모노 / 컬러"로 v2와 바꿔 볼 수 있다.

| 항목 | Moto 원본 | 투자 나침반 (모노) |
|---|---|---|
| 바탕 / 글자 | #080808 / #E1E5E5 | 밝은 화면 #E1E5E5 / #080808, 어두운 화면은 원본 그대로 |
| 보조 글자 | #666F76 (대비 4:1, 기준 미달) | 밝은 #4F575D, 어두운 #9AA1A6 (둘 다 5.8:1) |
| 강조색 | 거의 없음 | 노랑은 핵심 숫자, 초록·빨강은 오름·내림에만 |
| 글꼴 | Neue Montreal 500 (상업 글꼴) | Pretendard 유지, 굵기 600으로 낮춤 |
| 버튼 | 알약 모양, 단색 | 같음 |
| 결과 판 | — | 파란 판 → 검정 판 |
| 3D, 큰 사진, 회원제 말투 | 있음 | 가져오지 않음 |

코드: `src/theme-mono.css` (html의 `data-design="mono"`일 때만 적용), 전환은 `src/lib/design.js`

## 1. 방향

**라이트 핀테크 + 인디고 그라디언트 + 유리 느낌 + 작은 움직임**

- 깔끔하지만 "AI가 만든 티"가 나지 않게, 이 앱만의 개성을 조금씩 더한다
- 서비스 이름이 나침반이므로 **나침반 모양(바늘, 눈금, 방위)** 을 곳곳에 쓴다
- 초보자용 앱이라 **화려함보다 읽기 쉬움**이 먼저다

## 2. 바꾸는 방식

- **한 번에 다 바꾸지 않고 조금씩** 바꾼다
- 기존 `App.css`, `Calculator.css`는 그대로 두고, **`src/theme.css`에 덧씌운다**
  - `App.jsx`의 `import './theme.css'` 한 줄을 지우면 원래 디자인으로 돌아간다
- 새 디자인은 **새 화면부터 시험**하고(예: 모의투자), 반응이 좋으면 다른 화면으로 넓힌다
- 다른 AI가 만든 CSS를 받으면 그대로 붙이지 말고, 아래 "꼭 지킬 것"에 맞는지 먼저 확인한다

## 3. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--cobalt`, `--brand` | `#3346F5` | 주 색, 강조, 결과 패널 |
| `--brand-glow` | `#6D7BFF` | 그라디언트 중간 |
| `--violet` | `#8B5CF6` | 그라디언트 끝, 보라 포인트 |
| `--sun` | `#FFD84D` | 나침반 바늘, 불어난 돈, 강조 배지 |
| `--warn` | `#C2410C` | 하락, 경고, 팔기 |
| `--night` | `#14172B` | 어두운 바탕(표지, 결과 띠) |
| `--paper` | `#F3F4F8` | 화면 배경 |

- 그라디언트: `--grad-brand` (인디고 → 연한 인디고 → 보라, 135도)
- **다크 모드 값이 반드시 함께 있어야 한다** (`index.css`, `theme.css`의 다크 모드 구역)
- 글자 색 대비는 **4.5:1 이상** (다크 모드 링크 대비를 2.6:1 → 8.0:1로 고친 적 있음)

## 4. 글꼴과 숫자

- 글꼴: **Pretendard** (`index.html`에서 불러옴, CSS의 `@import` 사용 안 함)
- 숫자 칸에는 `font-variant-numeric: tabular-nums` (자릿수가 흔들리지 않게)
- **금액은 읽기 쉬운 한국어 단위**로: `13,458만` 대신 **1억 3천만원**
- 제목은 굵고 크게, 설명은 짧게. 한 화면에 핵심 항목은 3~6개

## 5. 모양

| 항목 | 값 |
|---|---|
| 카드 모서리 | 20px (`--radius-card`), 작은 것 14px |
| 테두리 | 인디고를 아주 옅게 (`--line`) |
| 그림자 | `--shadow-sm` 기본, 올리면 `--shadow-md`, 주 버튼 `--shadow-glow` |
| 상단바 | 반투명 유리 + 흐림 효과, 스크롤해도 위에 붙음 |

- **둥근 카드를 모든 곳에 반복하지 않는다.** 숫자 비교는 선으로 나눈 표, 상황 설명은 왼쪽 굵은 선처럼 화면마다 리듬을 다르게 (모의투자 화면 참고)

## 6. 움직임

- 속도 곡선: 부드러운 감속 `--ease-out`, 통통 튀는 `--ease-spring`
- 화면이 열릴 때 위에서부터 차례로 떠오름 (`.screen` 아래 요소)
- 올리면 살짝 떠오름, 누르면 살짝 눌림
- 이 앱만의 움직임: **나침반 바늘이 흔들리다 자리 잡기, 눌러서 돌리기**
- **움직임 줄이기 설정을 켠 사용자에게는 움직임을 끈다** (어지러움 배려)

## 7. 꼭 지킬 것 (바꾸기 전 확인)

- [ ] 다크 모드에서 흰 카드나 흰 상단바가 떠 보이지 않는가
- [ ] "제목 + 보조 문구" **두 줄 버튼**이 한 줄로 뭉개지지 않는가
- [ ] 계산기의 **넓은 화면 2단 배치**가 유지되는가 (`#root`에 폭 제한 금지)
- [ ] 아이폰 **노치 여백**이 두 번 들어가지 않는가
- [ ] 기존 **클래스 이름을 바꾸지 않았는가** (화면이 많아서 이름이 바뀌면 깨짐)
- [ ] 홈, 진단, 결과, 계좌, 계산기, 모의투자, 학습 화면을 **전부 한 번씩** 열어봤는가

## 8. 피할 것

- 특정 종목·상품·금융회사가 눈에 띄게 강조되는 디자인
- 모든 곳에 그라디언트 (주 버튼, 진행바, 강조 몇 곳에만)
- 작은 글씨로 정보를 많이 넣기
- 이모지를 아이콘 대신 쓰기 (직접 그린 그림이나 아이콘 사용)

## 9. 다음에 바꿔볼 후보

- 진단 진행바를 **나침반 눈금** 모양으로 (모의투자 진행 표시처럼)
- 결과 화면의 안정·중립·적극형을 **나침반 방위**처럼 표현
- 계산기 결과 금액이 바뀔 때 **숫자가 굴러가는 효과** 넓히기
- 학습 화면들의 카드 반복을 줄이고 화면마다 다른 배치
