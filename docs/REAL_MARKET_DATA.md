# 모의투자 실제 시장 데이터 (v3)

교수님 제안(실제 지수 반영으로 신뢰성 높이기)에 따라, 가상 시장 5가지를 **실제로 있었던 3년 구간 10개**로 바꿨다.

## 출처

| 나라 | 데이터 | 출처 |
|---|---|---|
| 한국 | 주가지수 월별 (코스피 기반, 2015=100) | OECD Main Economic Indicators, FRED `SPASTT01KRM661N` (2026-10-15 갱신본) https://fred.stlouisfed.org/series/SPASTT01KRM661N |
| 미국 | S&P 500 월평균 | Robert Shiller(Yale) 데이터, datasets/s-and-p-500 https://github.com/datasets/s-and-p-500 |

- 두 데이터 모두 **월평균**이라 하루 중 최저점보다는 덜 떨어져 보인다 (화면에 안내)
- OECD 데이터는 출처 표기 필수 (FRED 표기: "Copyrighted: Citation Required")

## 선택 순간

구간마다 6개. 실제 숫자로 오름·하락·반등·최고점을 판정하고, 제목("고점보다 44% 떨어졌어요")도 실제 숫자로 계산한다.
60개 순간 모두 판정이 숫자와 맞는지 자동 검사 통과. (us2022 21개월째는 처음에 '제자리'로 판정됐으나 4개월 +8.9%라 '반등'으로 고침)

## 2단계: 매일 갱신되는 최근 3년

| 항목 | 내용 |
|---|---|
| 데이터 | 금융위원회_지수시세정보 (공공데이터포털, 한국거래소 전일 종가) https://www.data.go.kr/data/15094807/openapi.do |
| 요청 주소 | https://apis.data.go.kr/1160100/GetMarketIndexInfoService_V2 |
| 실행 | GitHub Actions `.github/workflows/update-market.yml`, 평일 18:00(KST) + 수동 실행 |
| 스크립트 | `scripts/update-market.mjs` → `public/data/market.json` (어제 종가, 37개월 월말 종가) |
| 인증키 | GitHub Secrets `DATA_GO_KR_KEY`에만 저장. 코드·파일·앱에 없음 |
| 앱 | `src/lib/liveMarket.js`가 저장소의 파일을 읽음. 못 읽으면 기존 10개 시장으로 동작 |
| Netlify | 자동 갱신 기록에 `[skip netlify]`를 붙여 배포 크레딧을 쓰지 않음 |

- API 응답 모양은 활용자가이드 확인 전이라, 기능 이름 두 가지를 차례로 시도하고 첫 실행 때 응답 모양을 기록(Actions 로그)하게 했다
- 받기에 실패하면 기존 파일을 그대로 둔다 (시험: 오류 응답일 때 파일 유지 확인)
- 최근 3년 시장의 선택 순간은 `autoMoments()`가 실제 숫자로 판정한다 (검토한 10개 시장에 같은 규칙을 돌려 9개 같은 결과, 나머지 1개도 숫자상 맞는 판정)
