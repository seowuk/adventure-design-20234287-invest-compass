## 1. 배경·목적

**배경**
투자에 관심은 있지만 ETF, 수익률, 분산투자 같은 용어부터 막혀서 시작조차 못 하는 20·30대가 많다. 정보는 인터넷에 넘치지만 "나에게 맞는" 방법을 짚어주는 곳은 없고, 매달 얼마씩 투자하면 미래에 얼마가 되는지 감도 잘 오지 않는다.

**목적**
투자 초보자가 자신에게 맞는 투자 방향을 진단받고, 복리 효과를 눈으로 확인하고, 수준에 맞는 학습 자료(책·뉴스)까지 한 곳에서 찾을 수 있는 **ETF 시작 도우미 서비스**를 제공한다.

## 2. 대상·사용자

| 구분 | 내용 |
|------|------|
| 주 사용자 | 투자를 시작하고 싶지만 용어·방법을 몰라 망설이는 20·30대 (대학생, 사회초년생) |
| 사용자 특징 | 투자 지식 거의 없음 / 목돈보다 소액 적립식 투자에 관심 / 유튜브·뉴스레터 등 쉬운 콘텐츠 선호 |
| 비대상 | 이미 투자 경험이 많고 심화 분석 도구가 필요한 사용자 |

---

## 3. 범위 (할 것 · 안 할 것)

**할 것**
- 간단한 질문을 통한 개인 맞춤 투자 성향·방향 진단
- 월 적립액·기대수익률·기간 기반 복리 시뮬레이션(표·그래프)
- 진단 결과 및 수준별 도서 추천
- 투자 학습용 뉴스·정보 사이트/채널 추천

**안 할 것**
- 실제 증권사 계좌 연동, 매매 주문 기능
- 특정 종목/ETF에 대한 매수 추천 ("사라"는 말 하지 않음)
- 실시간 시세 제공, 포트폴리오 자산 관리

## 4. 핵심개념 (도메인)

| 용어 | 설명 |
|------|------|
| ETF (상장지수펀드) | 여러 종목을 묶어 하나의 상품처럼 거래소에서 사고파는 펀드 |
| 복리 | 원금뿐 아니라 이전에 붙은 수익에도 다시 수익이 붙는 방식 |
| 분산투자 | 하나의 자산에 몰아넣지 않고 여러 자산에 나누어 투자하는 전략 |
| 적립식 투자 | 목돈이 아닌 매달 일정 금액을 꾸준히 투자하는 방식 |

> 상세 정의는 `13_용어집.md`에서 관리

## 5. 시스템 구성 개요

```
[사용자]
   │
   ▼
[진단 화면] → 투자 성향·목표 질문 응답
   │
   ▼
[진단 결과] → 투자 유형 안내
   │
   ├─▶ [복리 계산기] → 적립액/수익률/기간 입력 → 표·그래프 결과
   │
   └─▶ [추천 화면] → 수준별 도서 추천 / 뉴스·정보 사이트 추천
```

- 별도 회원가입·로그인 없이 이용 가능한 구조를 우선 검토 (개인정보 최소 수집 원칙)
- 복리 계산은 서버 없이 클라이언트에서 즉시 계산하는 구조를 우선 검토 (상세 근거는 `08_아키텍처_ADR.md`에서 ADR로 기록)

## 7. 가정·제약

**가정**
- 사용자는 투자 지식이 거의 없는 '초보자'라고 가정한다
- 계산기 결과는 참고용 시뮬레이션이며 실제 수익을 보장하지 않는다는 점을 사용자가 인지한다

**제약**
- 1인 프로젝트, 한 학기 내 완성해야 함 → 기능 범위를 진단·계산기·추천 3~4개로 제한
- 실시간 금융 데이터 연동은 하지 않음 (외부 API 비용·인증 이슈 회피)
- 투자 자문업 관련 법적 이슈를 피하기 위해 특정 종목 추천은 절대 하지 않음
