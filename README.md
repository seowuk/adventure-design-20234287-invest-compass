   # 투자 나침반 (Invest Compass)

> 종목은 고르지 않습니다. 방향만 알려드립니다.

투자를 시작하고 싶지만 용어부터 막히는 20·30대를 위한 **ETF 입문 도우미**입니다.
몇 가지 질문으로 투자 출발점을 진단하고, 복리 효과를 눈으로 확인하고,
내 돈에 맞는 계좌(일반 계좌·ISA·연금저축·IRP) 방향을 안내합니다.

- 로그인 없음, 개인정보 수집 없음 (진단 결과는 사용자 브라우저에만 저장)
- 특정 종목·상품·금융회사를 추천하지 않음

## 주요 기능

| 기능 | 설명 |
|---|---|
| 투자 성향 진단 (6문항) | 감수할 **마음**과 감당할 **여건**을 따로 재고, 더 조심스러운 쪽을 출발점으로 제시 |
| 진단 결과 | 출발점이 나온 이유 설명, 경계 점수 안내, 비상금·단기자금 경고, 직접 고르기 |
| 자금 성격 진단 (3문항) | 돈을 쓸 시점과 세액공제 가능 여부로 자유형·중기형·장기형 판정 |
| 계좌 안내 | 자금 성격에 맞는 계좌 방향, ISA 일반형·서민형 비교, 4개 계좌 비교표 |
| 복리 계산기 | 월 적립식 복리 계산, 연도별 그래프, 성향별 예시 수익률 |

## 실행 방법

[Node.js](https://nodejs.org) LTS 버전이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

> Windows PowerShell에서 실행 정책 오류가 나면 `npm` 대신 `npm.cmd`를 사용하세요.

## 기술 스택

- React 19 + Vite
- Recharts (그래프)
- Pretendard (폰트)
- 서버 없음: 모든 계산은 브라우저에서 수행

## 폴더 구조

```
src/
├── App.jsx            화면 전환
├── screens/           화면별 컴포넌트 (시작, 진단, 결과, 계좌 안내, 계산기)
├── components/        공통 컴포넌트 (상단바, 접이식 설명 등)
├── data/              문항·결과 문구·계좌 제도 데이터  ← 문구 수정은 여기서
└── lib/               판정 로직, 저장
docs/                  기획·명세 문서
```

## 진단 설계 요약

v1.0(5문항 합산)을 전수 검증한 결과 모순 판정과 과도한 경계 점수가 발견되어 v1.1로 재설계했습니다.

1. 위험 감수 **의향**과 감당 **능력**을 분리하고, 둘이 다르면 낮은 쪽을 따름
2. 의향은 형식이 다른 세 문항(하락 반응, 확률 선택, 목표 선호)을 같은 무게로 합산
3. 능력(쓸 시점, 비상금)은 합산하지 않고 상한선으로 사용
4. 투자 경험은 성향이 아니므로 점수에서 제외

| 검증 항목 (전체 응답 조합) | v1.0 | v1.1 |
|---|---|---|
| 모순 판정 | 48건 | 0건 |
| 투자 경험만 바꿔도 결과가 바뀌는 비율 | 51% | 0% |

자세한 근거와 검증 계획은 `docs/03_기능명세서` 4장을 참고하세요.
이 진단은 교육용 자가점검이며 검증된 심리검사가 아닙니다.

## 주의: 세금 관련 수치

`src/data/accounts.js`의 ISA·연금저축·IRP 수치(비과세 한도, 세액공제 한도 등)는
**검증 전 초안**입니다. 국세청·금융감독원 자료로 확인한 뒤
`RULES.verified`를 `true`로 바꾸면 화면의 "검증 전" 표시가 사라집니다.
